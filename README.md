# Pendulum / Lab

단일·이중 역진자를 실제 수치 물리로 움직이고 Jev의 판단 네트워크와 로컬 제어기를 비교하는 웹 실험실입니다. Jev 모드에서 세우는 일은 전적으로 Jev가 맡습니다.

## 실행

Node.js 24 이상을 권장합니다.

```powershell
git clone https://github.com/doroper98/Jev_Pendulum.git
cd Jev_Pendulum
npm ci
npm run dev
```

표시된 로컬 주소를 브라우저에서 여세요. 현재 기본 주소는 http://localhost:3000 입니다.

처음에는 정지해 있습니다. **시작**은 실행 또는 이어 하기, **스탑**은 현재 상태 보존 및 정지, **재시작**은 같은 설정의 초기 상태로 돌아가 즉시 실행합니다.
재시작 시 이전 실행은 비교 목록에 남습니다. 기록 재생 중 재시작은 저장된 첫 프레임부터 재생합니다.
Space는 시작/스탑이며, 한 스텝은 20 ms만 진행합니다. 설정이나 제어기 변경 후에는 다시 시작을 눌러야 움직입니다.
API 키 없이 자동 제어를 보려면 **로컬 자동 제어**를 선택하고 시작을 누르세요.

`.env`에 TypeSafe에서 발급받은 키를 설정하고 개발 서버를 다시 실행하세요.

```dotenv
TYPESAFE_API_KEY=your_key
JEV_MODEL=jev-latest
```

키는 서버 전용이며 브라우저 번들·실험 기록·Git 저장소에 포함하지 않습니다.
호스팅 버전에서는 Sites 비밀 환경 변수에 같은 이름으로 설정해야 합니다.
로컬 키 설정이 호스팅으로 자동 복사되지는 않습니다.

## 실험 원칙

- 초기 기본값: 아래로 매달린 단일 막대 / 단일 Jev / 실시간형.
- 물리 엔진은 힘과 중력·감쇠에 따른 운동만 적분합니다.
- Jev 모드에는 PID, LQR, MPC, 자동 Swing-up, 행동 추천, 미래 예측, 숨은 보정이 없습니다.
- 마지막 Jev가 반환한 LEFT/RIGHT를 그대로 ±설정 힘으로 적용합니다.
- 중간 노드의 오류를 코드 규칙으로 교정하지 않습니다. 모델 실패도 실험 결과입니다.
- API 오류·잘못된 응답·한도 초과 시 일시정지합니다. 다른 제어기나 데모로 자동 대체하지 않습니다.
- 로컬 자동 제어·수동·무작위는 명시적으로 선택하는 별도 비교 모드입니다.
- Jev의 내부 사고 과정은 제공되지 않습니다. UI는 실제 입력·노드 선택·분포·confidence·지연·결과를 표시합니다.

## 네트워크

| 구성 | 실제 Jev 판단 노드 | 순차 API 요청 / 제어 스텝 |
| --- | --- | --- |
| A 단일 | 행동 1 | 1 |
| B 직렬 | 자세 → 전략 → 행동 | 3 |
| C 병렬 묶음 | 자세·회전·레일 → 행동 | 2 |
| D 순환 다층 | 자세·회전·레일 → 전략·이전 행동 효과 → 행동 | 3 |

같은 층의 질문은 하나의 API 요청에 담고 Jev가 독립 평가합니다.
다음 층에는 원래 물리 상태와 이전 층의 실제 선택·확률이 들어갑니다.
D는 이전 3스텝의 상태·행동·중간 선택을 되먹임합니다. 가중치 갱신이나 온라인 학습은 하지 않습니다.
전략 노드의 출력은 다음 Jev의 입력일 뿐이며, 하드코딩된 제어기를 실행하지 않습니다.

단일은 최대 초당 10 제어 스텝, 다층은 최대 5스텝이며 스텝 간 네트워크 요청을 겹치지 않습니다.
한 다층 스텝은 원본 관측 상태를 유지하며 평가합니다.
판단 대기형에서는 전체 네트워크 응답이 올 때까지 가상 시간이 멈춥니다.
실시간형에서는 응답 대기 동안 이전 힘이 유지되며 관측과 적용 시각을 각각 기록합니다.
물리는 1×로 진행하지만 API 응답이 늦으면 오래된 힘이 유지되어 균형을 놓칠 수 있습니다.
인사이트에서 전체 응답 시간, 서버↔Jev 요청 시간, 나머지 앱 왕복·처리 시간을 나누어 확인합니다.
추가 지연이 없는 로컬·수동·무작위는 두 시간 모드 모두 실제 시간과 같은 속도(1×)로 진행합니다.
프레임 사이의 남은 시간을 누적하고 고정 20 ms 스텝을 필요한 횟수만큼 실행하므로 화면 주사율과 물리 속도가 분리됩니다.
Jev 판단 대기형은 요청을 기다리는 만큼 느려지는 것이 정상이며, 화면에 프레임률과 실제 시간 대비 진행 배율을 표시합니다.
화면은 기록된 두 물리 상태 사이를 보간합니다(최대 한 스텝 지연). 이 보간은 제어·기록·성공 판정에 영향을 주지 않습니다.
계측·차트의 정기 React 갱신은 초당 최대 10회로 제한하고, 시작·스탑·오류 등은 즉시 표시합니다.
탭을 벗어나거나 프레임 간 지연이 0.5초를 넘으면 명시적으로 일시정지합니다.

## 로컬 자동 제어 — 현재 상태에서 온라인 탐색

저장된 기준 궤적·힘 배열·사전 최적화 데이터를 사용하지 않습니다. 이전 버전의 `local-plans.json`과 오프라인 생성 스크립트는 제거했습니다.
시작을 누르면 **그 순간의 관측 상태**에서 첫 제어 계획을 계산하고, 완료되면 물리가 움직입니다.
브라우저 Web Worker가 비선형 MPC(iLQR)를 계산하므로 후속 탐색 동안 화면·물리는 계속 진행합니다. API 키·외부 추론 서버·API 요금이 없습니다.

- 초기 후보는 힘 0이며, 물리 방정식으로 미래 상태를 예측하고 각도·속도·수레 위치·힘·레일 이탈 비용을 줄이도록 후보 힘을 최적화합니다.
- 단일은 5초, 이중은 7초를 내다봅니다. 이는 **예측 구간**이며 정해진 동작 시간이나 전환 시각이 아닙니다.
- 탐색 중에는 약 120 ms 간격으로 최신 상태를 다시 관측합니다. 이전 계산이 진행 중이면 중복 계산하지 않습니다.
- 직전 온라인 계산 결과만 다음 탐색의 초기 후보로 재사용합니다. 실제 관측에서 다시 예측하며 저장된 동작으로 복귀하지 않습니다.
- 계산 지연 중에는 이번 실행에서 얻은 최근 계획과 현재 상태의 피드백을 적용합니다. 계측에 재계획 횟수·최근 계산 시간·관측 시각·힘을 남깁니다.
- 현재 상태에서 직립 피드백으로 잡을 수 있는지 짧게 예측한 뒤 균형 제어로 전환합니다. 균형 피드백 계수도 물리 모델의 Riccati 식으로 실행 중 계산합니다.
- 크게 넘어지면 현재 상태에서 새 탐색을 시작합니다. 레일 이탈이나 시험 종료 후에는 상태를 되돌리거나 세워 놓지 않습니다.
- 예측 모델은 같은 운동 방정식의 40 ms RK4 근사이며, 실제 물리는 기존 최대 5 ms 적분을 유지합니다. 예측 오차·최적화의 지역해·계산 지연 때문에 실패할 수 있습니다.
- 제어기가 반환하는 것은 수레의 힘뿐입니다. 위치·각도·속도는 물리 적분 결과이며 탐색 결과로 덮어쓰지 않습니다.

기본 조건(최대 제어력 10 N, 추가 응답 지연 0)의 30초 수치 실험에서 단일·이중 모두 온라인 swing-up과 4 N 수레 외력 후 균형을 검증합니다.
이중 막대는 단일보다 탐색이 어렵고 오래 걸립니다. 임의의 외력·초기 상태에서 성공을 보장하지 않으며, 계산 속도에 따라 결과도 달라집니다.
Jev는 ±최대 힘 중 하나를 고르고 로컬은 그 범위 내 연속적인 힘을 사용하므로 같은 행동 공간의 비교는 아닙니다.
**Jev 모드에는 로컬 예측·제어가 개입하지 않으며 Jev 오류를 다른 제어기로 대체하지 않습니다.**

## 수레 직접 조작

- 실행 중 수레 몸체를 마우스나 터치로 잡고 좌우로 드래그합니다.
- 드래그 위치는 목표점일 뿐, 실제 수레 위치를 바꾸지 않습니다. 스프링·감쇠 외력 `clamp(35 × 위치 차이 − 5 × 수레 속도, −20, 20) N`으로 당깁니다.
- 좌우 밀기 버튼 또는 A/D 키는 누르는 동안 −4/+4 N을 가합니다. 손을 떼거나 화면을 벗어나거나 스탑하면 해제합니다.
- 실제 적분 힘은 `제어기 힘 + 사용자 외력`입니다. 사용자 외력은 제어기 최대 힘과 별개이며 강하게 밀면 레일을 벗어날 수 있습니다.
- 막대 건드리기는 관절에 0.12 N·m·s의 충격량을 가하며, 질량 행렬을 통해 연결된 수레·막대의 속도 변화를 함께 계산합니다.
- 프레임 기록에 제어력·사용자 외력·합력이 각각 남습니다. 드래그 시작·해제 이벤트도 기록하고 재생 중에는 새 외력을 넣지 않습니다.
- 아래에서 세우기는 넘어져도 레일 안에서는 재시도합니다. ‘균형 유지’ 시험은 기존 기준대로 ±12° 이탈 시 종료합니다.

## 물리와 성공 기준

질량 없는 강체 링크와 끝점 질점을 사용하는 Euler–Lagrange 질점 모델입니다.
이중 막대의 두 각도는 모두 위쪽 수직을 기준으로 한 절대각입니다. 두 번째 각도는 상대 관절각이 아닙니다.

- 수레 1 kg, 중력 9.81 m/s², 레일 ±2.4 m
- 단일: 길이 1.5 m, 끝점 질량 0.2 kg
- 이중: 길이 0.85 / 0.75 m, 질량 0.15 / 0.12 kg
- 수레 감쇠 0.06 N·s/m, 관절 감쇠 0.002 N·m·s/rad
- RK4 최대 5 ms 적분, 20 ms 관측 기록
- 균형 유지 시험은 ±12° 이탈 시 종료
- Swing-up 시험은 회전 제한 없음, 레일 이탈 또는 설정 시간에 종료
- 모든 막대가 ±12° 및 각속도 1 rad/s 이내를 2초 연속 유지하면 비교표에 성공 표시

레일 경계에서 반사·순간 이동·각도 고정 등을 하지 않습니다.
성공 판정은 계측일 뿐 물리 상태에 영향을 주지 않습니다.

## 기록과 비교

시드·목표·구조·힘·시간 모드·추가 지연·입력 표현을 같게 두고 네트워크만 바꾸세요.
종료/초기화한 최근 20회의 개별 결과를 현재 페이지 세션에서 비교합니다.
각 실험은 상태·행동·노드 판단·모델 응답명·지연·사용량을 JSON으로 내보내고 재생할 수 있습니다.
재생은 API를 호출하지 않습니다. 외란은 별도 이벤트로 남깁니다.

네트워크·비교표의 호출·토큰 열은 **최종 판단까지 완료된 스텝**에 대한 값입니다.
화면 상단 요금 패널은 각 API 요청에서 확인된 토큰을 모으므로 다층 요청의 중간 실패에서도 앞선 호출의 사용량을 포함합니다.
입력 100만 토큰당 $0.042, 출력 무료라는 공개 단가(2026-09-19 확인)로 예상 USD 금액을 계산합니다.
이번 실험 요금과 페이지 누적 요금을 구분하며, 재시작해도 페이지 누적은 유지됩니다. 새로고침하면 페이지 누적이 초기화됩니다.
실패·취소 등으로 응답을 받지 못한 요청이나 토큰 미보고 호출은 미확인으로 표시합니다. 미확인 부분을 무료로 간주하지 않습니다.
예상 요금에는 다른 페이지·기기의 사용, 크레딧, 세금 등을 반영하지 않습니다. 최종 청구액은 TypeSafe 콘솔에서 확인하세요.
JSON 기록에도 사용량을 저장하며, 기록을 재생해도 페이지 누적 요금에 추가하지 않습니다.
API가 반환한 모델 이름이 별칭이면 구체적인 모델 버전으로 임의 변환하지 않습니다.
